## Abstract

> This thesis presents an experimental agent-based discussion system using large language models
> (LLMs), in which agents are assigned personas generated by a RAG-based (Retrieval-Augmented
> Generation) module that draws on information collected from the web about a given discussion topic.
> This RAG-based method is compared with a baseline method, which relies only on information encoded
> in the model weights. The study was conducted using two topics relevant to the Lithuanian context
> and two LLMs differing in architecture and parameter count. The results show that the RAG-based
> method creates more diverse personas; however, this difference does not produce a measurable effect
> on agents' voting behavior – the dominant factor shaping the discussion dynamics remains the
> combination of the model and the topic.

**Keywords:** large language models, multi-agent systems, RAG, society simulation, discussion systems,
agent persona generation, LLM bias
